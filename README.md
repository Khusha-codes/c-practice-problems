# Mario Pyramid (CS50 Style)

This is a simple C program that prints a double pyramid using `#`.

## Features

* Takes user input for height
* Validates input (must be positive)
* Uses nested loops

## Example Output

```
   # #
  ## ##
 ### ###
#### ####
```

## Concepts Used

* Functions in C
* Loops (for loop)
* Input validation (do-while)
